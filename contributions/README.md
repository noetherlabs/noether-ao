# Diffraction-Dragrace benchmark patch

[`dragrace.patch`](dragrace.patch) adds a small-pupil matrix-Fourier-transform case
and p99/maximum timing columns to
[Diffraction-Dragrace](https://github.com/Jashcraf/Diffraction-Dragrace).
The [reproduction guide](../docs/reproduction.md#dragrace-benchmark) gives the
pinned source revision and reconstruction commands.

The upstream MIT notice is retained in
[`licenses/Diffraction-Dragrace-LICENSE.txt`](licenses/Diffraction-Dragrace-LICENSE.txt).
It applies to the upstream project and derived patch, not Noether AO as a whole.
